# 灭火器喷火 Mod（OC2 Extinguisher Flamethrower）

把游戏里的灭火器改造成"火焰喷射器"：

- 对着任意可燃物喷（炉灶、搅拌台、食材箱……），会直接把它点燃，火焰还会像正常着火一样向周围蔓延。
- 喷射特效复用原灭火器特效、颜色改成橙色；**音效始终是原版灭火器音效**。
- 拿着灭火器的人自己仍然不会被点燃（和原版一样防火），方便你"安全"地到处放火。
- 使用灭火器喷射时可以正常移动（原版喷射时会原地站住）。
- **对玩家喷射会模拟"着火"**（需开启配置，默认关闭）：玩家衣服逐渐变红、头顶冒火苗，并用原版重生倒计时 UI（染成橙色、一半大小、位置可配置）显示 5→1 倒计时。5 秒后若还在地面上，则以原版"被车撞死"动画死亡（不播车撞音效），并在原版出生点重生；中途掉水/掉落等被原版机制杀死时，只取消火焰状态、播放原版死亡动画，不影响其他任何死亡方式。
- 按 **G 键**（可在配置里改）在"喷火"和"灭火"两种模式之间切换，**默认灭火**。
- 在**公开街机/路人房固定自动禁用**（写死的，不可配置），不影响路人。

## 安装

把 `BepInEx\plugins\OC2ExtinguisherFlamethrower.dll` 放进游戏的 `BepInEx\plugins` 文件夹（构建脚本会直接输出到那里），然后启动游戏即可。

## 配置

配置文件在 `BepInEx\config\me.gloaming.oc2.extinguisher-flamethrower.cfg`（无分组，直接在 `[]` 下），可以修改：

- `当前模式`：显示当前是 `灭火` 还是 `喷火`（随 G 键切换实时更新，也可在配置里直接切换）。
- `切换按键`：切换模式的按键，默认 `G`（下拉列表按字母顺序排列）。
- `点燃玩家`：是否允许喷火点燃玩家（衣服变红 + 头顶火苗 + 橙色倒计时后死亡重生）。**每次启动都会重置为关闭**，可在 F1 配置管理器里实时开启。
- `倒计时位置X / 倒计时位置Y / 倒计时位置Z`：着火倒计时 UI 的显示位置偏移（玩家本地坐标），默认 `0 / 3.6 / 0`（头顶正上方、火焰特效之上）。可在 F1 配置管理器里实时调整。

> 每次启动游戏都会自动重置为**灭火状态**和**无法点燃玩家**状态。

## 编译（改源码后）

在 `Mod_bak\OC2ExtinguisherFlamethrower` 目录下运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

需要系统装有 .NET Framework 3.5 的 `csc.exe`（Windows 自带）。

## 说明与注意

- 原版灭火器的"灭火"逻辑被完全替换，本 mod 下灭火器**不再能灭火**（除非按切换键切回灭火模式）。
- **水枪（Water Gun）完全不受影响**：不会点燃、不改特效、不改移动，保持原版喷水/清洗/击退行为。
- 公开街机/路人房（`GameMode.OnlineKitchen` + 公开/匹配大厅）中本 mod 自动失效；好友私房和本地联机不受影响。
- 在线联机时，只有主机需要安装本 mod（游戏逻辑在主机上模拟）。
- 与"灭火器清洗"mod（OC2ExtinguisherWash）可共存：**喷火模式下自动跳过清洗逻辑**（避免边喷火边洗盘子），灭火模式下清洗照常。没装清洗 mod 时本功能自动忽略。
- 只影响"本来就能着火"的物体（炉灶、搅拌台、食材箱、火堆等）；普通纯装饰桌子原本就不支持着火，无法点燃。
- 玩家着火为模拟实现（原版无此机制）：皮肤变红是主机本地视觉，死亡重生走原版重生流程。

## 实现方式

通过 BepInEx + Harmony 补丁：

- `ServerFireExtinguishSpray.UpdateSynchronising`：喷出范围内所有带 `ServerFlammable` 的物体直接调用 `Ignite()`，替换原版的 `FightFire()` 灭火逻辑。
- `ClientSprayingUtensil.StartSpray`：复用原灭火器特效，把粒子材质颜色改成橙色（与尾气改色 mod 同样的方法）；音效不做任何修改，保持原版。
- `PlayerFireSystem`：检测到玩家在喷火锥内时把厨师衣服逐渐染红、头顶挂火苗，并复用原版重生倒计时 UI（单独实例化、橙色、半尺寸、位置可配置）显示倒计时，5 秒后用 **Car 重生类型**触发原版"被车撞死"死亡动画（通过 `TriggerAudio` 补丁只取消车撞音效），重生回原版出生点。
- 火焰中途被原版机制杀死：在每帧检测玩家重生标志（`PlayerControls.m_bRespawning`），检测到就取消火焰状态，不干预原版死亡流程。
- `WashGuard`：喷火模式下跳过"灭火器清洗"mod 的清洗逻辑（软依赖，未安装时自动忽略）。
- 音效补丁：喷火模式下取消点火音效（`FireIgnition`）和持续燃烧音效（`Flames` 循环），灭火模式和街机/路人房不受影响；火焰死亡时只取消车撞音效（`PlayerSlip`）。
- 按键切换/街机禁用通过配置和 `ServerGameSetup.Mode` + `LobbySetupInfo.m_visiblity` 检测实现。
