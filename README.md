# 灭火器喷火 Mod（OC2 Extinguisher Flamethrower）

Overcooked! 2（胡闹厨房 2）的 BepInEx 插件：把灭火器改造成"火焰喷射器"，还可以模拟"点燃玩家"。

## 功能特性

- **喷火点燃可燃物**：对准炉灶、搅拌台、食材箱等喷射即可点燃，火焰会正常蔓延。
- **橙色喷射特效**：复用原灭火器特效并染成橙色，喷射时人物可以移动。
- **一键切换模式**：按 G 在"喷火 / 灭火"之间切换（默认灭火，每次启动自动重置）。
- **模拟点燃玩家**（可选，默认关闭）：点燃后衣服变红、头顶冒火苗、显示 5 秒倒计时，倒计时结束死亡并重生。
- **街机/路人房自动禁用**：不影响路人。
- **水枪不受影响**：保持原版喷水/清洗/击退行为。

## 安装

1. 游戏需要已安装 [BepInEx 5](https://docs.bepinex.dev/)。
2. 把 `OC2ExtinguisherFlamethrower.dll` 放到游戏的 `BepInEx\plugins` 文件夹。
3. 启动游戏即可生效。

## 使用

- 拿起灭火器，按 **G** 切换"喷火 / 灭火"模式（默认灭火）。
- 喷火模式下对着炉灶等可燃物喷射即可点燃。
- 在配置里开启"点燃玩家"后，对着队友喷射会使其着火（衣服变红 + 火苗 + 5 秒倒计时后死亡重生）。

## 配置

配置文件：`BepInEx\config\me.gloaming.oc2.extinguisher-flamethrower.cfg`

| 配置项 | 说明 | 默认值 |
| --- | --- | --- |
| 当前模式 | 显示当前是"灭火"还是"喷火"，随 G 键实时更新 | 灭火 |
| 切换按键 | 切换喷火/灭火的按键 | G |
| 点燃玩家 | 是否允许点燃玩家（每次启动重置为关闭） | false |
| 倒计时位置X / Y / Z | 着火倒计时的显示位置（玩家本地坐标） | 0 / 3.6 / 0 |

## 注意事项

- 喷火模式下灭火器**不再能灭火**（除非切回灭火模式）。
- 在线联机时只有主机需要安装本 mod（游戏逻辑在主机上模拟）。
- 玩家着火为模拟实现（OC2 原版没有玩家着火机制）。
- 与"灭火器清洗"mod（OC2ExtinguisherWash）兼容：喷火模式下自动跳过清洗逻辑。

## 兼容性

- BepInEx 5 / Harmony 2
- 水枪（Water Gun）不受影响
- 与 OC2ExtinguisherWash 可共存
